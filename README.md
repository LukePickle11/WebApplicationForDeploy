# WebApplicationForDeploy

Simple Maven WAR project for the CSCI 475A continuous deployment tutorial.

## Build

```bat
mvn clean compile package
```

The WAR should be created under:

`target\WebApplicationForDeploy-0.0.1-SNAPSHOT.war`

## Web files

- `src/main/webapp/index.html`
- `src/main/webapp/WEB-INF/web.xml`
- `pom.xml`
